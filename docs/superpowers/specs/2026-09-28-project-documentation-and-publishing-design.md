# 外呼系统文档与仓库交付设计

## 目标

将已实现的手机 SIM 智能外呼系统完整同步到 `whitekk414/waihu-system`，并同时满足业务汇报和研发交接的阅读需求。

## 交付范围

- 上传 Java 业务服务、Asterisk/ARI 配置、SenseVoice 语音识别服务、Web 测试页、测试用例、部署脚本及预录话术。
- 不上传客户录音、运行日志、本地数据库、模型权重、Python 虚拟环境、Android 工具包、密钥、真实手机号和设备 MAC 地址。

## 文档结构

### README.md

面向业务与研发的统一入口，包含项目目标、当前进度、核心能力、系统架构、业务对话流程、目录结构、快速启动、安全边界和后续工作。

### docs/DEPLOYMENT.md

面向研发与运维，记录 Windows/WSL2、JDK 17、Maven、Python、Asterisk、USB 蓝牙适配器和 Android 手机的前置条件，以及 ARI、chan_mobile、SenseVoice、Java 服务和环境变量的安装、启动与健康检查步骤。

### docs/TESTING.md

面向测试和业务验收，包含 Java/Python 自动化测试、外呼前检查、真人通话验收脚本、预期分支、结果查看方式和常见故障排查。

## 发布策略

1. 补齐三份文档并核对所有路径、环境变量和启动命令。
2. 运行 Java 和 SenseVoice 自动化测试。
3. 扫描待提交文件，排除敏感信息与运行产物。
4. 将文档作为独立提交追加到已完成的功能提交。
5. 推送当前完整历史到目标仓库 `main` 分支；如目标分支已有独立历史，先拉取检查后再决定合并，不强制覆盖。

## 验收标准

- GitHub 目标仓库可见完整源码、配置模板、测试、话术音频和三份交付文档。
- README 中的文档链接、目录和命令与实际项目一致。
- Java 和 Python 自动化测试通过。
- 仓库不包含真实通话录音、运行日志、密钥、真实设备标识和本地大文件。
